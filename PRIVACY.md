# Privacy

Last updated: 2026-10-09

## Data we collect

The widget does not send analytics or personal data to a Pendo Act service. A saved recording is stored only in the visitor's browser `localStorage` under `pact.recorder.plan`.

## How data is used

The widget uses the entered task text and any locally stored recording only to select and execute automation steps in the current browser session. It does not transmit this data itself.

## Third parties

The widget runs inside the host application and may interact with that application's existing pages. Distribution of the bundle and data handling by the host application or its provider are governed by their respective policies.
